# Support

Tirion is available as a public source preview.

## Supported In Preview

- Source install from a clean checkout.
- Node.js 24.
- Go 1.24 or newer for the source-built terminal TUI.
- Local agent, `tirion-tui`, and `tirionctl` operation.
- macOS source-based local development.
- Linux source-based local development on a best-effort preview basis.
- Explicitly watched repositories.
- Supported local telemetry surfaces for Claude Code, Codex, Cursor, and GitHub
  Copilot where documented.
- Local webhook delivery to a user-configured sink.

## Unsupported In Preview

- Windows.
- npm package installation.
- VS Code extension packaging or Marketplace distribution.
- Remote backend sync or backend-to-agent control.
- GitHub Check publishing.
- Organization reporting or accounting sync.
- Prompt drilldown or execution-content export.
- Exact billing reconciliation.
- Unwatched repository attribution.

Security issues must be reported through `SECURITY.md`, not public support
issues.
