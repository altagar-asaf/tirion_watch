# Code Of Conduct

Tirion should be a practical, respectful project for people building local-first
developer tools.

Expected behavior:

- Be respectful and constructive.
- Assume good intent, and ask clarifying questions before escalating.
- Keep reports reproducible without exposing private prompts, code, telemetry,
  repository names, credentials, or local paths.
- Accept maintainer decisions about privacy, security, and product scope.

Unacceptable behavior:

- Harassment, threats, insults, or discriminatory language.
- Publicly sharing another person's private data, secrets, repository contents,
  prompts, logs, or vulnerability details.
- Repeatedly pushing unsupported scope such as backend sync, organization
  reporting, prompt drilldown, or exact billing claims into preview docs/issues.

Report conduct concerns privately to the project maintainer. Maintainers may
remove comments, close issues, block users, or take other action needed to keep
the project safe and focused.
